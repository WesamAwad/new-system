# TicketRedesign.md — SwiftFix Ticket Creation Redesign Guidelines

## 1. الهدف العام

إعادة تصميم وبناء شاشة "إنشاء طلب الصيانة" (`resources/js/pages/tickets/create.tsx`) لتتطابق تماماً مع الهوية البصرية، والنمط التصميمي، والمكونات المعتمدة في بقية صفحات تطبيق "سويفت فيكس" (Inertia + React + Tailwind CSS).

---

## 2. معايير التصميم وألوان الثيم (Tailwind Theme Standards)

- **الاتجاه واللغة:** دعم كامل للغة العربية والاتجاه من اليمين إلى اليسار (`dir="rtl"`).
- **الهيكل العام:** استخدام الهيدر الموحد (`<Header />`) والفوتر الموحد (`<Footer />`) للفرونت إند.
- **اعتماد متغيّرات ثيم Tailwind المخصصة في المشروع:**
    - **اللون الرئيسي (Primary):** استخدام كلاسات الثيم المعرفة مثل `bg-primary`, `text-primary`, `border-primary`, و `ring-primary`.
    - **خلفية الصفحة (Background):** استخدام الكلاس المعتمد في الثيم للخلفيات العامة (مثل `bg-muted` أو `bg-slate-50`).
    - **النصوص والعناوين (Typography):** استخدام كلاسات ألوان النصوص المعتمدة بالثيم (مثل `text-foreground`, `text-heading`, `text-muted-foreground`).
    - **البطاقات والحقول (Cards & Inputs):** خلفية العناصر باللون المعتمد للشاشات والبطاقات، مع حدود خفيفة ناعمة ونصف قطر انحناء مطابق لثيم المشروع (`rounded-xl` أو `rounded-2xl`) وظل خفيف (`shadow-sm`).

---

## 3. التوزيع والتقسيم الهيكلي للشاشة (Grid Layout)

تتكون الصفحة على الشاشات الكبيرة من نظام شبكي ذي عمودين مفصولين (`lg:grid-cols-3`):

### أولاً: القسم الرئيسي (Main Section - بعرض عمودين `lg:col-span-2`)

1. **بطاقة الورشة المختارة (Workshop Context Banner):**
    - عرض الرمز التعبيري / الشعار للورشة.
    - اسم الورشة، المدينة، والعنوان بالتفصيل.
    - شارة توضيحية بأسلوب لطيف (`طلب موجه مباشرة`) باستخدام ألوان الشارات المعتمدة في الثيم.
2. **بطاقة نموذج البيانات (Form Card):**
    - **قائمة اختيار الخدمة (`service_id`):** قائمة منسدلة بالخدمات التي تقدمها الورشة حصراً مع السعر الابتدائي لكل خدمة.
    - **عنوان الطلب / الملخص (`title`):** حقل نصي قصير للعنوان العريض للمشكلة.
    - **تفاصيل المشكلة (`description`):** حقل نصي متعدد الأسطر للتوضيح المفصل.
    - **العنوان ورقم التواصل (`address`, `phone`):** حقول تعبئة تلقائية استناداً إلى بيانات
